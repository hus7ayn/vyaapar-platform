- R5 categories: item-category create needs client slug + no dup handling (categories.service.ts:16). No add-category UI for items/expenses (hotel room-types has one).
- R6 credit settle: only via POST /sale/payments-in (auto-allocates FIFO). No settle button on party/ledger UI.
- R9 return: refund API exists (sale.service.ts:112 refundInvoice, credit-notes, debit-notes). Missing UI button only.
